## 迁移结果

- 原有 25 个应用 JavaScript 文件迁移为 TypeScript；54 个 Vue 单文件组件使用 `script setup lang="ts"`。

- 补全 API、组件、表单、路由、Store、持久化数据及异常处理类型；区分 JSON 响应信封与 Blob 下载响应。运行时校验重点覆盖信封和不可信输入，并非所有业务响应的完整 Schema 校验。
- 保留现有 Vue、Vite 等依赖版本，没有安装、升级依赖。工具配置及 Node 测试脚本继续使用 JavaScript。
- 修复直接关联的数据与交互问题：选项 A-D 转换、分页参数、来源列表、科目编辑控件、确认取消、深层树拖拽事件、选项复制及 Markdown 重复章节。
