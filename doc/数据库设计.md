# 当前项目数据库设计

范围：`backend-fastapi/data/web408.db`，后端使用的 SQLite 数据库。

已通过只读方式核对当前真实数据库；SQLite 版本为 3.49.1，共 11 张非系统表，其中 10 张为当前 ORM 映射业务表，`schema_migrations` 为历史结构记录表。SQLite 内部表 `sqlite_sequence` 不作为业务表展开。字段类型、默认值、索引、约束和外键以当前数据库 DDL 为准；字段含义和值域结合当前代码整理。

## `user`

用途：保存用户账号、认证凭据、角色和启用状态。

| 字段 | 实际类型 | 可空/默认 | 说明 |
|---|---|---|---|
| `id` | `INTEGER` | 非空，主键，`AUTOINCREMENT` | 用户 ID |
| `username` | `TEXT` | 非空 | 用户名 |
| `password` | `TEXT` | 非空 | Argon2 密码哈希，不保存明文密码 |
| `email` | `TEXT` | 可空，无默认值 | 邮箱 |
| `role` | `TEXT` | 非空，默认 `'USER'` | 用户角色，数据库允许 `ADMIN`、`USER`、`GUEST` |
| `enabled` | `INTEGER` | 非空，默认 `1` | 账户是否启用，代码中的布尔值以 `1/0` 存储 |
| `create_time` | `TEXT` | 非空，无数据库默认值 | 创建时间，应用按 UTC 时间写入 |
| `update_time` | `TEXT` | 非空，无数据库默认值 | 更新时间，应用按 UTC 时间维护 |

索引与约束：
- 主键：`id`。
- 唯一约束：`username`；SQLite 自动索引为 `sqlite_autoindex_user_1`。
- CHECK：`role IN ('ADMIN', 'USER', 'GUEST')`。
- 外键：无。

用途：保存考研科目及其展示顺序、启用状态。

| 字段 | 实际类型 | 可空/默认 | 说明 |
|---|---|---|---|

| `name` | `TEXT` | 非空 | 科目名称 |
| `code` | `TEXT` | 非空 | 科目编码 |
| `description` | `TEXT` | 可空，无默认值 | 科目描述 |
| `order_num` | `INTEGER` | 非空，默认 `0` | 展示顺序 |
| `enabled` | `INTEGER` | 非空，默认 `1` | 是否启用，代码中的布尔值以 `1/0` 存储 |
| `create_time` | `TEXT` | 非空，无数据库默认值 | 创建时间 |
| `update_time` | `TEXT` | 非空，无数据库默认值 | 更新时间 |

索引与约束：
- 主键：`id`。
- 唯一约束：`name`；SQLite 自动索引为 `sqlite_autoindex_subject_1`。
- 唯一约束：`code`；SQLite 自动索引为 `sqlite_autoindex_subject_2`。
- 外键：无。

## `chapter`

用途：保存科目下的章节树及章节启用、排序信息。

| 字段 | 实际类型 | 可空/默认 | 说明 |
|---|---|---|---|

| `subject_id` | `INTEGER` | 非空，无默认值 | 所属科目 ID |
| `parent_id` | `INTEGER` | 可空，无默认值 | 父章节 ID；根章节为空 |
| `name` | `TEXT` | 非空，无默认值 | 章节名称 |
| `order_num` | `INTEGER` | 非空，默认 `0` | 同级章节排序 |
| `enabled` | `INTEGER` | 非空，默认 `1` | 是否启用，代码中的布尔值以 `1/0` 存储 |

## `exam_question`

用途：保存按年份和题号组织的考研真题。

| 字段 | 实际类型 | 可空/默认 | 说明 |
|---|---|---|---|
| `id` | `INTEGER` | 非空，主键 | 真题 ID |
| `create_time` | `TEXT` | 非空，无数据库默认值 | 创建时间 |
| `update_time` | `TEXT` | 非空，无数据库默认值 | 更新时间 |
| `year` | `INTEGER` | 非空，无默认值 | 真题年份 |
| `question_number` | `INTEGER` | 可空，无默认值 | 题号 |
| `question_type` | `TEXT` | 非空，默认 `'ESSAY'` | 题型，数据库允许 `CHOICE`、`ESSAY` |
| `title` | `TEXT` | 可空，无默认值 | 题目标题 |
| `content` | `TEXT` | 非空，无默认值 | Markdown 格式题目内容 |
| `options` | `TEXT` | 可空，无默认值 | 选择题选项 JSON 文本 |
| `answer` | `TEXT` | 可空，无默认值 | 题目答案 |
| `category` | `TEXT` | 可空，无默认值 | 分类名称数组 JSON 文本 |
| `subject_id` | `INTEGER` | 可空，无默认值 | 所属科目 ID，允许历史数据为空 |
| `difficulty` | `TEXT` | 可空，无默认值 | 难度，非空时允许 `EASY`、`MEDIUM`、`HARD` |
| `author_id` | `INTEGER` | 非空，无默认值 | 创建或维护该题目的用户 ID |

索引与约束：
- 主键：`id`。
- 普通索引：`idx_exam_question_subject_id`（`subject_id`）。
- 普通索引：`idx_exam_question_author_id`（`author_id`）。
- 唯一索引：`uq_exam_question_year_number`（`year`, `question_number`），条件为 `question_number IS NOT NULL`。
- CHECK：`question_type IN ('CHOICE', 'ESSAY')`。
- CHECK：`difficulty IS NULL OR difficulty IN ('EASY', 'MEDIUM', 'HARD')`。
- 外键：`subject_id` → `subject.id`，删除策略为 `SET NULL`。
- 外键：`author_id` → `user.id`，删除策略为 `RESTRICT`。

## `exam_process_image`

用途：保存真题讲解过程图片与真题之间的关联，不把过程图片写入题干或答案 Markdown。

| 字段 | 实际类型 | 可空/默认 | 说明 |
|---|---|---|---|
| `id` | `INTEGER` | 非空，主键 | 过程图片关联 ID |
| `create_time` | `DATETIME` | 非空，无数据库默认值 | 创建时间 |
| `update_time` | `DATETIME` | 非空，无数据库默认值 | 更新时间 |
| `exam_id` | `INTEGER` | 非空，无数据库默认值 | 关联真题 ID |
| `filename` | `VARCHAR` | 非空，无数据库默认值 | `uploads/images/` 下的图片文件名 |
| `sort_order` | `INTEGER` | 非空，无数据库默认值 | 同一真题下的展示顺序，应用层默认从 `0` 开始 |
| `created_by` | `INTEGER` | 非空，无数据库默认值 | 上传管理员 ID |

索引与约束：
- 主键：`id`。
- 普通索引：`ix_exam_process_image_exam_id`（`exam_id`）。
- 组合索引：`ix_exam_process_image_exam_sort`（`exam_id`, `sort_order`）。
- 普通索引：`ix_exam_process_image_created_by`（`created_by`）。
- 外键：`exam_id` → `exam_question.id`，删除策略为 `CASCADE`。
- 外键：`created_by` → `user.id`，删除策略为 `RESTRICT`。
- 删除本表关联只会将图片从真题过程展示中移除，不立即删除物理文件；物理文件由现有图片资源治理和未引用清理机制管理。

| 字段 | 实际类型 | 可空/默认 | 说明 |

| `update_time` | `DATETIME` | 非空，无数据库默认值 | 更新时间，应用按 UTC 时间维护 |
| `title` | `VARCHAR` | 可空，无默认值 | 题目标题 |
| `question_type` | `VARCHAR` | 非空，无数据库默认值 | 题型，应用默认 `ESSAY`，允许 `CHOICE`、`ESSAY` |
| `content` | `VARCHAR` | 非空，无默认值 | Markdown 格式题目内容 |
| `options` | `VARCHAR` | 可空，无默认值 | 选择题选项 JSON 文本 |
| `answer` | `VARCHAR` | 可空，无默认值 | 题目答案与解析 |
| `category` | `VARCHAR` | 可空，无默认值 | 分类名称数组 JSON 文本 |
| `subject_id` | `INTEGER` | 可空，无默认值 | 所属科目 ID，允许历史数据为空 |
| `difficulty` | `VARCHAR` | 可空，无默认值 | 难度，非空时允许 `EASY`、`MEDIUM`、`HARD` |
| `author_id` | `INTEGER` | 非空，无默认值 | 创建或维护该题目的用户 ID |

索引与约束：
- 主键：`id`。
- 普通索引：`ix_adaptation_question_subject_id`（`subject_id`）。
- 普通索引：`ix_adaptation_question_author_id`（`author_id`）。
- CHECK：`question_type IN ('CHOICE', 'ESSAY')`。
- CHECK：`difficulty IS NULL OR difficulty IN ('EASY', 'MEDIUM', 'HARD')`。
- 外键：`subject_id` → `subject.id`，删除策略为 `SET NULL`。
- 外键：`author_id` → `user.id`，删除策略为 `RESTRICT`。

## `adaptation_source`

用途：保存改编题与一条或多条真题来源之间的引用关系。来源事实键为「年份 + 题号」，可跨年份；`exam_question_id` 是按事实键解析出的可选真题 ID，不替代年份和题号事实。

| 字段 | 实际类型 | 可空/默认 | 说明 |
|---|---|---|---|
| `id` | `INTEGER` | 非空，主键 | 来源引用 ID |
| `create_time` | `DATETIME` | 非空，无数据库默认值 | 创建时间 |
| `update_time` | `DATETIME` | 非空，无数据库默认值 | 更新时间 |
| `adaptation_id` | `INTEGER` | 非空，无默认值 | 改编题 ID |
| `source_year` | `INTEGER` | 非空，无默认值 | 来源真题年份 |
| `source_question_number` | `INTEGER` | 非空，无默认值 | 来源真题题号 |
| `exam_question_id` | `INTEGER` | 可空，无默认值 | 解析命中的真题 ID，未命中时为空 |

索引与约束：
- 主键：`id`。
- 普通索引：`ix_adaptation_source_adaptation_id`（`adaptation_id`）。
- 普通索引：`ix_adaptation_source_exam_question_id`（`exam_question_id`）。
- 组合索引：`ix_adaptation_source_source`（`source_year`, `source_question_number`），用于真题反查与覆盖统计。
- 唯一约束：`uq_adaptation_source_ref`（`adaptation_id`, `source_year`, `source_question_number`）。
- 外键：`adaptation_id` → `adaptation_question.id`，删除策略为 `CASCADE`。
- 外键：`exam_question_id` → `exam_question.id`，删除策略为 `SET NULL`。

来源引用删除改编题时级联删除；删除真题时只清空解析出的 `exam_question_id`，保留年份和题号事实，避免真题库变更造成改编记录丢失。

| 字段 | 实际类型 | 可空/默认 | 说明 |
|---|---|---|---|
| `version` | `TEXT` | 非空，主键，无默认值 | 迁移或结构变更版本标识 |
| `applied_at` | `TEXT` | 非空，无默认值 | 版本应用时间 |

索引与约束：
- 主键：`version`；SQLite 自动索引为 `sqlite_autoindex_schema_migrations_1`。
- 外键：无。
