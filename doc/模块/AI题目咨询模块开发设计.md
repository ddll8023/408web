## 1. 功能范围

### 1.1 保留的业务目标

- 真题、模拟题、改编题阅读页提供“AI 咨询”，不覆盖管理端，也不建设通用聊天首页。
- 个人中心按供应商管理自己的 API Key 和独立启用状态；数据结构与前端选择器支持多个供应商，当前注册表只收录 OpenCode Go，后续增加供应商只需追加注册表项。默认咨询型号与供应商凭据分开保存，不因浏览或切换供应商自动改选型号。
- 保存凭据、查询目录、保存默认选择和真实检测是不同操作；本批已不提供联网目录刷新。保存或打开页面不自动调用模型，目录收录不代表当前账号有调用权限。
- 提供流式回复、连续追问、停止和关闭；只有用户明确发送或确认检测才发起模型生成，不自动换模型、重试、摘要压缩或预热。
- 题目上下文包含题干、A-D 选项、参考答案解析、科目及分类。允许参考解析透露答案，面板明确提示；参考解析不是绝对正确的系统指令。
- 后续图片范围保留站内 PNG / JPEG / WebP、GIF 首帧、内联 SVG 和 SVG 代码块；SVG 规范化为 PNG 后交给支持图像的具体型号。
- 聊天只存在服务器和页面内存，不写数据库、localStorage 或 sessionStorage；刷新、关闭、服务重启后不能恢复。
- 打开咨询前退出题目全屏 / 沉浸，关闭后不自动恢复。退出浏览器全屏失败时提示手动退出，不打开咨询或调用模型。

### 1.2 本次 Python 迁移的边界

本次迁移目标是替换 AI Node 服务和 Pi JavaScript SDK 调用层，保留已形成的配置、安全与文本咨询业务行为，不把整个网站改成 Python 前端，也不只是由 Python 启动 Node 后继续调用原 SDK。

- 目标运行结构为现有 Vue 前端加 FastAPI 后端，AI 由 FastAPI 进程内的 Python 模块执行，不再新增 AI 监听端口或独立常驻 AI 服务。
- 模型层已锁定 `pydantic-ai-slim[openai,anthropic]==2.53.0`，目录为随应用发布的冻结注册表；Go 型号按三种协议分别映射。
- 注册表经用户确认只收录 `opencode-go`：数据模型、加密凭据、双修订与前端选择器仍保留多供应商能力，后续增加供应商只需追加注册表项。
- 现有个人设置页面继续复用，仅按新目录来源和 SDK 语义调整契约与说明，不重塑设置 UI。
- 题目页入口、聊天面板、安全回答渲染和图片链路不纳入本批迁移实现，后续另报清单；它们仍属于完整功能目标。
- 保留当前数据库、已保存配置及加密主密钥。不重建表、不添加迁移链、不重置凭据，不自动删除旧 Node 文件、依赖或内部认证文件。

### 1.3 不建设的能力

聊天历史同步、同账号多套默认配置档案、自定义供应商端点、订阅 OAuth、宿主 IAM / ADC / 云账号凭据发现、普通用户上传图片、外链图片抓取、独立讲解过程图自动携带、OCR、联网搜索、题库检索、文件 / 终端 / Skill / MCP 工具，以及模型回写题目均不在范围内。

按本地单 FastAPI worker 设计，不建设多 worker 配额协调、独立准备任务系统、跨服务容量握手、通用元数据平台、自研 DNS 拨号、会话级连接池、常驻图像进程池或完整系统沙箱。

## 2. 调用链与职责

### 2.1 现行实现与迁移目标

现行源码已使用进程内调用链，回环 Node 依赖已移除：

```text
Vue 个人中心 / 后续阅读页
  → FastAPI：网站鉴权、配置事务、可信题目快照
  → 进程内 Python AI 运行模块：固定目录、账号生成位、会话、流与停止
  → PydanticAI 模型层：按型号协议转换消息与流事件
  → 当前用户选择的供应商与型号
```

原 `127.0.0.1:7790` Node 服务及其 `ai-agent/` 源码已被删除，Git 无记录，无法再作为回滚路径；FastAPI 与 Vite 启动都不依赖它。旧回环客户端 `integrations/ai_agent_client.py`、`ai_local_secrets.get_agent_service_token` 与 `AiConfig.agent_port` 已同批删除；`service.token` 文件保留但已无代码读取。

- FastAPI 沿用现有 Bearer Token 鉴权，账号只取认证结果；配置、会话、检测、停止和关闭都校验账号归属。
- 请求级 Service / Repository 负责数据库读取与显式写事务。复制所需普通字段和可信快照后回滚读事务，再进行主密钥文件读取、线程解密或长时间网络等待，不把 ORM 对象传给生成任务。
- 应用 lifespan 统一管理进程内 AI 运行模块、会话与活跃生成；导入或构造本身不发模型请求、不联网读取目录。
- AI 运行模块不接收任意文件路径、端点、请求头、系统提示词或工具定义。业务层传入经过校验的账号、双修订、型号、快照与原请求标识。
- 优先采用 PydanticAI 的底层模型请求接口，只使用模型与消息转换能力，不启用 Agent 编排、工具或宿主资源加载。候选库不能满足必要兼容要求时先重新确认选型，不能擅自退回 Node。
- 首版只有一个提供业务请求的 FastAPI worker。内存会话、互斥和失效记录不能跨 worker 共享；开发热重载和服务重启会清空聊天，不能声称会话可恢复。
- 阻塞文件操作在线程中执行；后续图像转换仍采用一次性普通子进程，不在主事件循环做解码或 SVG 渲染，不新增常驻服务。

## 3. 个人配置、供应商与模型目录

### 3.1 接入范围与协议适配

接入范围经用户确认为**单一供应商** `opencode-go`：固定端点、单一 API Key，不接受浏览器自定义端点，也不让远程元数据决定请求地址。注册表只收录该供应商，数据模型、加密凭据、双修订与前端选择器仍保留多供应商能力，后续增加供应商只需追加一条注册表项。

模型层选取 `pydantic-ai-slim[openai,anthropic]==2.53.0`，只使用其模型与消息转换、流事件能力；底层使用自建 `AsyncOpenAI` / `AsyncAnthropic` 客户端，显式关闭重试、环境代理与重定向，显式传入 Key，不使用环境凭据兜底。

Go 型号按协议逐项映射，不能一律调用 Chat Completions：

| 协议 | 固定地址 | 型号 | Python 入口 |
| --- | --- | --- | --- |
| `openai-completions` | `https://opencode.ai/zen/go/v1` | DeepSeek V4/V4.1 系、GLM-5.2/5.3、Hy3/Hy4、Kimi K2.7/K3、LongCat、MiMo、MiniMax-M2.7、Qwen3.7/3.8、Space Bunny | `OpenAIChatModel` |
| `openai-responses` | `https://opencode.ai/zen/go/v1` | GPT-5.6/6 Luna、Grok 4.6/4.7、Muse Spark 1.2/1.3 | `OpenAIResponsesModel` |
| `anthropic-messages` | `https://opencode.ai/zen/go` | MiniMax-M3、Qwen3.8 Flash | `AnthropicModel` |

- 两种 OpenAI 协议型号固定 `max_tokens` 字段、`system` 角色与 `store=false`；`openai-responses` 型号请求 `reasoning.encrypted_content` 以支持无状态多轮。
- DeepSeek 系型号额外发送 `thinking:{type:enabled|disabled}` 与按 `thinkingLevelMap` 映射的 `reasoning_effort`，并在多轮请求的 assistant 消息上回传 `reasoning_content`。
- 每次请求携带 `x-opencode-session` 与 `x-opencode-client`。Pi 0.99.2 的客户端标识为 `pi`，本站不是 Pi 客户端，按“不伪装未使用的客户端”约定改为 `408web`；三种协议的检测实测均已被上游接受，咨询档位与流式仍未验证。
- 上下文与输出上限、图像能力、`thinkingLevelMap` 均以 `runtime/go_catalog.py` 的冻结快照为准；未收录型号直接拒绝，不猜测协议或能力。
- 静态能力声明不是账号权限或真实调用证明；三协议真实有效性仍需获准的模型调用验证，未验证前不得宣称已支持。

### 3.2 四类操作分离

| 操作 | 语义与边界 |
| --- | --- |
| 供应商凭据 | 每账号、每供应商独立保存加密 Key 和启用状态；切换供应商不覆盖其他 Key |
| 模型目录 | 浏览供应商与型号、搜索和分页；型号能力来自元数据，不代表当前账号获准调用 |
| 默认选择 | 只保存用户明确选择的已保存、已启用供应商及精确文本型号，不携带 Key |
| 真实检测 | 用户确认可能消耗额度后，使用已保存且修订匹配的 Key 发一次短文本，不发送题目或聊天 |

首次保存一个供应商必须提供 Key；缺省、null 或空白仅保留同供应商已有密文，不通过空密码隐式删除。明文输入在保存成功、离页、账号变化或卸载时清空，不写持久化 Store、浏览器存储、URL 或日志。

删除默认选择保留全部供应商凭据。删除当前默认供应商时，在同一写事务内先清默认引用再删除该供应商，不影响其他供应商，也不撤销上游 Key。清除和检测均有独立确认，保存不会自动检测。

默认设置保留 `provider_id`、`model_id`、`input_mode`、`enabled` 和 `revision`。当前前端只保存纯文本；后端 `text_image` 契约和具体型号图像能力不等于网站图片链路已经可用，图片未接入时明确拒绝，不悄悄退回文本。

### 3.3 目录来源

目录改为随应用发布的冻结注册表：`runtime/go_catalog.py` 由 `@earendil-works/pi-coding-agent` 0.99.2 内嵌目录提取（MIT，2026-10-03），公开来源值改为 `bundled`，前端解析与文案已同步。原 Pi 依赖已随 `ai-agent/` 删除，本表**无法再自动生成**，更新型号只能手工维护或重新安装 Pi。

本批**未接入联网目录刷新**：`/models/refresh` 与前端“联网刷新目录”按钮已一并删除。以下行为保留：

- 启动、查询、搜索、分页、保存设置和创建会话不联网、不隐式调用模型。
- Models.dev（MIT，`api.json` 约 1 MB）经评估只提供名称、limit、cost、modalities、reasoning 等元数据，**没有协议、地址与 compat 字段**，无法替代协议注册表，本批未接入，也不向其发送任何用户 Key。
- 型号须具有有效文本能力、明确归属与实际 ID；窗口、输出、推理和图像元数据不得靠型号名猜测，未知必要字段不制造默认能力。
- 目录内容不能引入新端点、动态 SDK 插件或任意认证方式；协议映射以服务端注册表为准。
- 检测、咨询与模型 HTTP 请求都不自动重试：底层 `openai` / `anthropic` 客户端显式 `max_retries=0`，PydanticAI 的 `retries` extra 未安装。

### 3.4 现有数据与双修订

以下两张表已经按当前 ORM 模型定向重建，本次语言迁移保留它们，不设计再次删库或迁移链：

| 表 | 字段与约束 |
| --- | --- |
| `user_ai_provider_config` | `user_id`、`provider_id`、`enabled`、`api_key_ciphertext`、`key_version`、`revision` 及公共字段；`(user_id, provider_id)` 唯一，关联用户 |
| `user_ai_config` | 唯一 `user_id`、`provider_id`、`model_id`、`input_mode`、`enabled`、`revision` 及公共字段；同账号供应商复合外键，不含 Key 字段 |

表模型包含通用 `id`、创建和更新时间；输入模式约束允许 `text` / `text_image`。Repository 不提交事务，写用例由 Service 显式提交。

供应商修订与默认选择修订分别在每次成功保存时生成新随机 UUID。会话与每轮请求绑定两类修订，删除重建也不复用旧修订；不新增前端并发版本协商，多标签仍按最后成功保存为准。

进程内实现已按此落地：读取配置前固定 60 秒登记期限，解密和发送等待不延长；配置提交后在同一进程内登记旧修订再停止匹配任务，保护记录最多 4096 条，未过期记录不因容量压力被淘汰。该实现已做无网络逻辑校验（期限过期、旧修订拒绝、容量拒绝），真实运行竞态尚未验收。

运行模块在同一进程内完成失效登记与任务取消，不再存在 HTTP 失效通知的送达依赖，保留以下安全边界：

- 截止时间在读取配置之前固定；创建、检测、消息登记及真正调用模型前校验期限和相关修订。
- 失效保护先于取消等待，准确区分账号、默认 / 供应商作用域及旧 UUID；迟到旧通知不能关闭新修订任务。
- 保护记录保留期与准入窗口匹配，到期回收；容量满时拒绝新准入，不淘汰仍有效保护后放行旧请求。
- 配置提交后的失效登记不能因用户不再等待响应而被遗漏；取消未确认不能释放生成位或伪造停止成功。
- 仅返回前复查配置不够，必须在模型调用前拒绝旧载荷，防止已经发生额度消耗后才丢弃结果。
- 单进程内存机制不扩展为分布式一致性保证，也不撤回已经发送的上游数据；重启会结束本地会话，不能承诺上游瞬时停止。

### 3.5 主密钥与旧内部凭据

继续使用 `cryptography.fernet.Fernet`，现行加密版本为 `1`，不复用 JWT、用户 Key 或旧内部 Token。主密钥独立于业务数据库和 Git：

- Windows：`%LOCALAPPDATA%/408web/ai/`，当前系统用户路径为 `C:/Users/17289/AppData/Local/408web/ai/`。
- macOS：用户 `Library/Application Support/408web/ai/`。
- 其他平台：`XDG_DATA_HOME` 或用户 `.local/share/408web/ai/`，拒绝非绝对基础路径。

`master.key` 已生成并须原样保留。仅首次明确保存新 Key 允许生成缺失主密钥；解密只能读取既有文件，缺失或损坏拒绝，不偷偷重建、覆盖或降级明文。私有临时文件写完同步后独占发布，拒绝链接、异常大小、格式和不安全权限；文件操作在线程中执行。Windows 依赖用户目录 ACL，不隔离同系统用户进程或管理员，不宣称完整沙箱。

`service.token` 是历史 FastAPI / Node 内部认证文件，不是加密主密钥。读取方（`get_agent_service_token` 与旧回环客户端）已随迁移删除，文件本身保留未删，也未使其失效于仍可能保留的旧部署。

主密钥必须独立备份，更换系统用户或机器时随加密数据库迁移；目前没有独立备份已完成的证据。丢失时恢复原文件，否则用户重新填写 Key，不能从数据库密文恢复主密钥。现有数据库备份不包含系统凭据，不自动清理或还原。

业务数据库继续由 Git 跟踪，Git 会保留历史密文，也不保护其他明文用户数据。轮换主密钥、删除本站配置和撤销上游 Key 是不同动作，不能声称删除当前记录就消除了历史风险。

## 4. 咨询、图片与流式流程

### 4.1 可信题目快照

浏览器创建会话只提交 `question_kind`（`exam` / `mock` / `adaptation`）和 `question_id`。FastAPI 复用对应详情查询，不信任客户端题面，不发送作者或本机路径；现有 `answer` 字段作为参考解析，不虚构独立答案和解析。

创建时固定题目文本及后续有界素材快照，追问沿用，不在每轮重新读取、哈希全部图片或同步题目编辑。修改题目或图片后需要新咨询，旧会话明确提示使用创建时内容。

当前实现将图片和 SVG 替换为未提供占位，不读取、转换或附图。后续图号须与实际附件对应；未选择或不可用的图明确标记未提供，不把 URL 当作模型看过图像，也不在文本中重复塞入 SVG、Base64 或路径。

系统提示词独立于题面和提问：中文 408 辅导，解释步骤、知识点和选项差异；参考解析可能有误，资料不足须说明不确定性。要求提示时优先给思路，不因题面、参考解析或用户消息改变工具权限。

### 4.2 内存历史、生成与取消

不可预测的 `session_id` 绑定账号、供应商与型号、双修订、题目标识和固定上下文。每次明确发送使用新 `request_id`，重复请求拒绝，不自动重发；检测 UUID 同样防重复。

- 每会话一个发送流程、每账号一个生成任务；检测与咨询共用生成位。忙碌时拒绝，不建设等待队列或跨 worker 配额。
- SDK 客户端和 Key 按当前账号隔离，不在共享可变客户端中切换认证，也不回退到宿主或其他账号 Key。每轮读取最新配置、结束读事务并解密，不因内存历史已有凭据而绕过主密钥不可用状态。
- 系统提示词、用户消息和模型协议历史存于有界内存。推理协议字段可为多轮兼容保留，但隐藏思考不能进入公开增量、完整回答或日志。
- 只有真实成功的完整终态保留历史并允许追问。调用前校验失败且历史未改变时可修正重发；生成后的停止、失败、超时或断流放弃会话，片段标记不完整。
- 停止只取消原 `request_id`；关闭放弃整个会话。首个流事件前需要停止时可关闭会话，迟到初始化或处理结果不得开始生成。
- 取消调用任务并关闭对应上游流，等待本地 SDK / 处理任务真实退出后释放占位；超时未确认时明确拒绝新生成。`Task.cancel()` 或关闭浏览器不是上游停止与费用撤销证明。
- 清理和终态回调都绑定原任务对象与请求，旧连接的迟到取消不能影响下一轮。应用退出等待有界收尾，不假报已回收全部任务。
- 关闭面板、切题、离开路由、退出账号及 KeepAlive 路由离开都安排原请求清理；突然断线由超时及闲置回收兜底。

不启用 Agent 的自动工具循环、输出修复重试或上下文压缩。纯 Python 不是放宽上述行为的理由；底层 SDK、HTTP 客户端及包装层的默认重试必须一起核对。

### 4.3 公开接口与 SSE

保留 `/api/ai` 下的鉴权 POST 接口和统一 `{code, message, data}`、snake_case 线格式；账号由认证提供，浏览器不能指定 `user_id`、Key 来源、系统提示词、端点、任意请求头或工具。

| 路径 | 用途 |
| --- | --- |
| `/providers/query` | 查询支持方式、限制及当前账号保存状态，不返回凭据 |
| `/providers/save` | 保存单供应商加密 Key 与启用状态，空 Key 仅保留已有值 |
| `/providers/delete` | 清该供应商及必要默认引用，不影响其他供应商 |
| `/models/query` | 离线搜索、分页或精确查询型号，不代表调用权限 |
| `/models/check` | 确认额度后用已保存修订发一次短文本检测，不含题目或聊天 |
| `/settings/query` | 查询独立默认选择，未配置返回 null |
| `/settings/save` | 保存明确所选供应商、型号、模式和启用状态，不携带 Key |
| `/settings/delete` | 只清默认选择，保留供应商凭据 |
| `/sessions/create` | 按题目标识固定可信快照，创建不调用模型 |
| `/sessions/{session_id}/messages` | 提交纯文本消息与新 UUID，以 POST SSE 返回回答 |
| `/sessions/{session_id}/abort` | 停止原 `request_id` |
| `/sessions/{session_id}/close` | 关闭会话并安排回收 |

现行会话视图是顶层 `question_kind` / `question_id`，不能假定存在嵌套 `question`。Key、密文和加密版本不回传；公开 `has_api_key` 仅表示凭据存在，保存或检测结果不能跨修订复用。

未登录 401；非法输入 / 不支持的型号或图片 422；忙碌、重复或修订失效 409；越权或未知会话 404；容量满 429；设施不可用或停止未确认 503；上游、超时或不完整响应 502。供应商认证失败不是网站登录过期，不能清网站 Token。

后续前端提问使用 `fetch` + POST SSE，复用网站 API 地址和 Token，不走 Axios JSON 拦截器或普通 15 秒超时。流建立前使用统一 JSON 错误；建立后使用以下事件：

| 事件 | 内容与要求 |
| --- | --- |
| `meta` | `session_id`、`request_id`、供应商与型号、输入模式；首个事件核对归属 |
| `delta` | 原 `request_id` 和公开回答增量，不包含隐藏思考 |
| `done` | 原 `request_id`、`completed` / `cancelled` / `failed`；成功完整 `answer` 或安全错误 |

SDK 流真实结束后核对正常结束原因、完整非空回答和取消意图，再交付唯一终态。不能只看到文本增量、连接 EOF 或某个通用结束事件就判成功；成功回答校正增量，终态后不追加内容。EOF 无 `done` 属于中断，不自动重发；取消和失败不携带可误认为成功的完整回答。

SSE JSON 编码须处理跨分片 UTF-8、换行与 LF / CRLF。移除内部 HTTP 转发后仍保留事件、回答与缓冲预算，以及有界背压；不使用无限队列。流迭代尚未开始就被取消、客户端停止等待目录或检测、以及发送终态失败时都须清理原任务。

前端节流渲染，处理中文输入法 Enter、不强拉用户滚动，并用账号 / 会话 / 请求标识拒绝旧结果；不因连接中断重新生成。

### 4.4 后续选图与转换

图片仍是完整功能目标，但不在本次 Python 文本迁移中实现，不能以模型目录的图像能力标识宣称已经附图：

1. 从当前题干、选项和参考解析识别站内位图、内联 SVG 和 SVG 代码块，生成编号、来源、可用状态及安全原因。
2. 只读取 `/uploads/images/` 下已授权的安全单文件名。绝对地址仅映射部署确认的本站来源，不抓外链，不用全题库文件名子串扫描代替授权。
3. 清单、读取和暂存均限制数量与字节。浏览器只能提交服务端生成的素材选择标识，不能提交路径、URL、SVG 原文或 Base64。
4. 首轮默认勾选可用图，可调整或主动选择纯文本。坏图、超限或字体设施不可用时明确拒绝，不静默少发、删除题意或回退文本后继续调用。
5. 静态安全 SVG 子集拒绝实体、脚本、事件、`foreignObject`、动画和外部图片 / 字体 / CSS 资源，不开放外部解析回调。
6. 保留方向规范化、等比例缩放、白底及真实内存 PNG 输出，使用固定 Noto Sans CJK SC 字体并保留许可，不靠改 MIME 冒充转换。
7. 采用一次性普通子进程，首轮逐图处理后退出；只传有界素材，不传 Key、主密钥或完整业务环境。超时 / 取消终止原进程并确认退出，迟到结果不能生成。
8. 首轮成功开始调用后固定模式与选图；规范化图片经 Python SDK 的正式图像消息接口送入模型，追问复用历史，改选需新会话。原始素材及时释放，附件仅存活跃会话内存。

原 `sharp` + `@resvg/resvg-wasm` 是未实施的 Node 图像候选，不再作为纯 Python 目标的既定方案。Python 位图库、SVG 渲染器或绑定、打包方式、许可和安全限制需另行核定；不能用 Node 包或 `session.prompt(text, {images})` 的旧调用形式冒充 Python 实现。

普通子进程不是完整安全沙箱，不引入 Docker / AppContainer 或常驻进程池，不开放任意图片上传。后续 SDK 图像编码、图像历史和具体型号视觉能力分别验收。

## 5. 安全底线与基础限制

### 5.1 模型调用隔离

- 不加载宿主 AGENTS、Skill、扩展、模板、SYSTEM、MCP、`auth.json` 或模型配置，不启用文件、终端、自定义工具或资源发现。
- Key 仅进入当前账号的私有 SDK 发送边界和短生命周期内存，不写客户端持久化、全局认证变量、模型目录缓存或协议历史。
- SDK 显式提供当前 Key 和固定端点，禁止宿主 API Key、订阅凭据、IAM / ADC 或其他账号认证兜底。
- 模型 HTTP 正常校验 HTTPS / TLS，不绕过证书、不自动向重定向地址转发认证，控制环境代理行为；不声称固定地址提供完整 DNS 重绑定防护。
- 咨询和检测不自动重试、回退型号、摘要压缩、预热或隐式生成；目录联网仅由用户主动操作，允许的最多两次管理重试不扩展到模型生成。
- 超时、断线、配置失效和应用退出清理原任务、上游流、计时器、客户端及图片引用；未确认停止不能提前释放生成位。
- 候选库的默认联网、遥测、日志回调、凭据发现和下层 SDK 重试须静态核对并在获准验证中确认；不能仅因使用底层接口就断言所有副作用已关闭。

### 5.2 日志、显示与隐私

日志只保留安全关联标识、耗时和状态，不记录认证头、明文 Key、密文、请求体、完整题目、提问或隐藏思考。沿用安全 Axios 错误摘要和 SQL `hide_parameters=True`；原始 SDK / 上游异常不得通过错误链、日志或响应泄露内容。

AI 回答使用独立 Markdown / KaTeX 清洗策略，不直接继承题目 SVG / `foreignObject` 白名单，不运行模型 HTML 或脚本。远程图片和其他自动资源在进入 DOM / 加载前受限，外链须显式点击；不修改全局题目渲染策略破坏原功能。

本地部署不等于离线。检测会向所选供应商发送短文本，咨询会发送题目、参考解析、提问和后续选图；图片历史可能再次发送并消耗额度。没有 usage 不代表零费用，不建设账单或价格估算平台，停止不能撤销供应商已收到的数据和已经发生的费用。

Go 的编码代理用途是否适用于题目辅导尚未确认。保留这一待核对项，不擅自换供应商，也不以使用 Pi 或 Python SDK 宣称已有用途许可。

### 5.3 有界初值

文本项来自现行实现，迁移原则上保留；图片项只是待实施的建议，不是性能或兼容承诺。调整仍须明确影响并获准验证，不建设复杂内存账本。

| 项目 | 初值与边界 |
| --- | --- |
| 每账号同时生成 | 1，检测与咨询共用；取消未确认仍占位 |
| 全局会话 / 生成容量 | 128；单账号最多 4 个咨询会话，检测纳入全局预算 |
| 生成总超时 | 咨询 120 秒；主动检测 30 秒 |
| 停止确认等待 | 5 秒；未确认时保留占位并拒绝新生成 |
| 闲置回收 | 30 分钟，忙碌会话不按闲置删除 |
| 每会话历史轮次 | 最多 12 轮，超限新建，不自动摘要 |
| 用户单条文本 | 最多 2,000 字符，另有 UTF-8 请求字节预算；Python / 浏览器计数差异须统一核对 |
| 请求正文 / 可信快照 | 现行内部正文 256 KiB、快照 64 KiB；移除 RPC 不等于允许无界公开请求 |
| 回答 / 历史 / 事件与缓冲 | 回答 64 KiB；历史、单事件及流缓冲分别最多 512 KiB |
| 目录 | 随应用发布的冻结注册表（29 个型号），无账号缓存、无刷新互斥与迟到结果问题 |
| 目录查询 | 搜索最多 200 字符；offset 0–100,000，limit 1–100 |
| 内部登记期限 / 失效保护 | 60 秒、最多 4096 条有效保护；容量满拒绝新准入，不淘汰有效记录 |
| 检测 UUID / 响应预算 | 最多 512 个 UUID、保留 30 分钟；检测文本加思考增量最多 8192 字节，思考不公开 |
| 图片处理 | 建议 30 秒，超时回收一次性子进程 |
| 选图与原始素材 | 建议最多 6 张、单张 5 MiB、合计 20 MiB；SVG 原文另设更小预算 |
| 位图规范化 | 建议解码前最多 1,600 万像素，输出长边最多 2,000 像素，不裁题意 |

具体型号更严格的限制优先。超限须明确提示修正或新建，不静默截断题目、丢图、淘汰安全保护或重试；无法完整交付的回答不标成功。

### 6.4 风险、回滚与参考

待核定项：咨询档位 `medium` 的真实请求（`thinking:{type:enabled}` + `reasoning_effort`）、SSE 流式与增量交付、多轮推理历史（`reasoning_content` 回传与加密推理回放）、停止确认与断线竞态、anthropic-messages 型号的空 thinking 签名行为、Go 编码订阅用途是否允许题目辅导，以及后续 Python 图像处理与字体资产。未核定不伪装完成，必要兼容缺口不擅自换库或缩减范围。

实施时保留可恢复的源码与依赖版本；`ai-agent/` 未提交即被删除且无副本，回滚到 Node 链路需重新获取 Pi 0.99.2 并重建 Node 服务源码与启动方式，不能仅重开 7790 就宣称回滚完成；不同时启用两套生成路径。纯 Python 运行层可停用 AI 而不影响普通读题。

数据库、现有配置、备份和 `master.key` 原样保留，不自动还原、清理或重建。恢复依赖、启停服务、删除旧实现和任何数据操作均需单独批准；回滚不能撤回已发往供应商的数据或费用。
