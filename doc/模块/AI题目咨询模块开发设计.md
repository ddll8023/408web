# AI 题目咨询模块开发设计

> 文档定位：本模块的初步设计，用于说明需求、范围、事实依据、大致设计思路、关键取舍、约束、风险与待定问题。不包含验证方向、测试计划、验收原则或通过标准。
> 粒度：协议字段、逐型号元数据、容量与超时常数、依赖与选型、文件级清单和具体实现留到各开发阶段按当次事实详细讨论，不在本文锁定。
> 状态：已实施（FastAPI 进程内 Python 运行模块 + 题目页非模态悬浮客服窗）。
> 使用边界：本文只作设计记录，不构成源码修改、依赖安装、数据库操作、服务启停、测试或真实模型调用的执行授权。

## 1. 文档定位与项目背景

- 本模块为真题、模拟题、改编题阅读页提供“AI 咨询”，并承接个人中心里的模型服务设置。
- 项目环境：Vue 3 + Vite 前端；单进程 FastAPI 后端；题库侧已有三类题目详情查询、网站鉴权与个人中心设置入口。
- 模块由来：早期实现为独立 Node 服务加外部 SDK 调用层，现已替换为 FastAPI 进程内的 Python 运行模块，前端技术栈与页面结构不变。
- 本文用途：后续迭代与维护时确认边界、职责与不变量，避免把实现细节当成需求。

## 2. 已确认需求、目标、范围与不做项

### 2.1 已确认需求

- 真题、模拟题、改编题阅读页提供“AI 咨询”；不覆盖管理端，不建设通用聊天首页。
- 个人中心按供应商管理 API Key 与独立启用状态；默认咨询型号与凭据分开保存，不因浏览或切换供应商自动改选型号。
- 保存凭据、查询目录、保存默认选择与真实检测是相互独立的操作；保存或打开页面不自动调用模型；目录收录不代表当前账号有调用权限。
- 题目上下文包含题干、A-D 选项、参考解析、科目与分类；允许参考解析透露答案并在面板明确提示，参考解析不是绝对正确的系统指令。
- 提供流式回复、连续追问、停止、收起与结束会话；只有用户明确发送或确认检测才发起生成，不自动换模型、重试、摘要压缩或预热。
- 咨询使用右下角非模态悬浮客服窗：不加整页遮罩、不锁题目滚动，窗口展开时会覆盖右下角部分内容；手机端使用高度受限的底部悬浮窗口。
- 全页只显示一个客服窗，标明当前咨询题目；收起后保留入口、草稿与聊天，重新展开不创建新会话。切换题目新建会话，生成中切题须确认结束原会话。
- 聊天只存在于服务器与页面内存：不写数据库、localStorage 或 sessionStorage；收起不清空，结束会话、离开当前页面或账号变化时清理，刷新与服务重启后不可恢复。
- 打开咨询前退出题目全屏 / 沉浸，收起或结束后不自动恢复；退出全屏失败时提示手动退出，不打开咨询也不调用模型。

### 2.2 本批已完成范围

- 把独立 Node AI 服务与外部 SDK 调用层替换为 FastAPI 进程内的 Python 运行模块。
- 题目页 AI 咨询入口（三类题目头部共用一套按钮）、唯一悬浮客服窗、流式追问、停止、收起恢复、结束会话与独立安全回答渲染；切题防串话及离页 / 账号变化清理。
- 前端目录语义与文案与服务端注册表同步。
- 图片链路：题目文本中指向本站上传目录的位图随会话固定上下文发送，内联 SVG 以源码文本进入上下文；缺失、超限、外链与非图像地址只登记原因并在会话说明中列出；模型不支持图像输入时拒绝创建会话并要求换型号。

### 2.3 本批保留与不重建

- 保留现有数据库、已保存配置与加密主密钥：不重建表、不添加迁移链、不重置凭据。
- 数据模型与前端选择器保留多供应商能力，但“当前是否需要支持新增供应商”不属本批需求，只作为现状能力记录（见 3.2）。

### 2.4 明确不做

聊天历史同步、同账号多套默认配置档案、自定义供应商端点、订阅 OAuth、宿主 IAM / ADC / 云账号凭据发现、普通用户上传图片、外链图片抓取、独立讲解过程图自动携带、OCR、SVG 转位图渲染、图像压缩与重编码、联网搜索、题库检索、文件 / 终端 / Skill / MCP 工具、模型回写题目。

### 2.5 范围外

图片增强：SVG 渲染、图像压缩、过程图自动携带与跨设备图片同步，后续另报清单，方法待定。

## 3. 项目事实、依据与假设

### 3.1 已确认事实（用户确认）

- 运行位置：AI 在 FastAPI 进程内执行，不新增端口、不启停独立服务。
- 供应商范围：注册表当前只收录 OpenCode Go。
- 数据保留：保留现有数据库、已保存配置与加密主密钥，不重建、不重置。

### 3.2 现状约束（来自现有实现，仅作事实与约束，不等于必须保留的需求）

- 后端为单 FastAPI worker：内存会话、互斥与失效记录不跨 worker 共享；热重载或重启会结束本地会话。
- 加密主密钥独立于业务数据库与 Git 存放；业务数据库由 Git 跟踪，历史密文随之保留。
- 三类题目详情查询、网站鉴权与题库快照已存在，可直接复用，不另建认证体系。
- 前端已具备个人模型服务设置、型号选择、咨询面板、回答渲染与会话客户端等独立层次。
- 供应商模型目录与协议元数据只能由服务端注册表提供；公共目录不含协议、地址与兼容性字段。

### 3.3 非阻塞假设

- 目前不需要跨刷新、跨设备或跨 worker 的聊天恢复。
- 当前用户量下单 worker 部署足够；如需多 worker，须重新评估会话、生成位与失效记录的设计。
- 模型目录变更频率低，随应用发布的冻结注册表可接受。

### 3.4 已按项目约定采用（非本设计新增）

- 认证与账号归属沿用现有网站鉴权与请求级依赖。
- 数据访问沿用现有 Service / Repository 与显式事务约定。
- 日志、字段命名与统一响应契约沿用项目既有约定。

### 3.5 依据来源

项目事实来自当前仓库实现与配置；用户确认范围来自本模块历次对话；涉及供应商文档、公开模型目录与第三方库行为的外部事实只作约束使用，具体内容与版本在各开发阶段按当次事实核对，不在本文锁定。

## 4. 大致设计思路与关键取舍

### 4.1 思路概述

- 运行位置：AI 在 FastAPI 进程内执行，取消独立 Node 服务与外部 SDK 调用层，不新增 AI 端口或常驻服务。
- 咨询形态：题目页右下角唯一的非模态悬浮客服窗，承载流式回复、连续追问、停止、收起恢复与结束会话；回答走独立安全渲染路径。
- 模型接入：服务端注册表承载协议与元数据，按型号协议分别适配，目录随应用发布冻结，不联网刷新。
- 数据边界：配置与凭据入库且加密，聊天与会话只在服务端内存与页面内存中存在。

### 4.2 关键取舍

| 决策 | 结论 | 依据与影响 |
| --- | --- | --- |
| 运行位置 | AI 在 FastAPI 进程内执行，不新增端口、不启停独立服务 | 消除跨服务失效通知的送达依赖与旧内部凭据；代价是单进程内存边界与重启即丢会话 |
| 供应商范围 | 注册表只收录 `opencode-go`，固定端点、单一 API Key | 用户确认；数据模型与前端保留多供应商能力，扩展只需追加注册表项，不改架构 |
| 协议与型号元数据 | 由服务端注册表承载，按型号协议分别适配，不一律走 Chat Completions | 公共目录没有协议、地址与兼容性字段，无法替代 |
| 模型层 | 使用底层模型请求接口加自建客户端，显式关闭重试、环境代理与重定向 | 需要逐参数控制；不启用 Agent 编排、工具或宿主资源加载 |
| 目录来源 | 随应用发布的冻结注册表，不接入联网刷新 | 协议字段只能来自服务端注册表；更新方式见 6.3 |
| 旧载荷防护 | 双修订加固定登记期限，配合进程内失效登记与取消 | 必须在额度消耗前拒绝旧载荷；具体期限与容量属实现常数，见 6.3 |
| 回答渲染位置 | 为回答区新建独立渲染实例，不复用题目区共享渲染组件 | 共享渲染实例的白名单是模块级并集，无法在不影响题目区的前提下按场景收紧；该判断依赖第三方库行为，属开发阶段核实事项 |
| 前端追问条件 | 仅上一轮为完整成功终态时才允许继续发送 | 后端只在成功终态把该轮追加进会话历史；否则追问会隐含丢失上一轮提问 |
| 图片链路 | 本站上传目录内的图片随会话固定上下文发送，内联 SVG 只以源码文本进入上下文 | 覆盖题目文本中真实存在的两种形态；把 SVG 渲染成位图需要渲染器与字体资产，代价高于收益；模型不支持图像输入时拒绝创建，而不是静默降级成纯文本 |

### 4.3 未采纳的方向

- 继续保留独立 Node AI 服务：需要跨服务失效通知、内部凭据与额外端口，收益不足以抵消复杂度。
- 多 worker 会话共享或外部会话存储：当前规模不必要，会把实现复杂度提前引入。

## 5. 架构、职责边界与必须保持的约束

### 5.1 数据流

```text
Vue 个人中心 / 题目阅读页
  → FastAPI：网站鉴权、配置事务、可信题目快照
  → 进程内 AI 运行模块：固定目录、账号生成位、会话、流与停止
  → 模型层：按型号协议转换消息与流事件
  → 当前用户选择的供应商与型号
```

### 5.2 分层职责与依赖方向

依赖单向：前端 → 网站后端 → 运行模块 → 模型层。

| 层 | 职责 |
| --- | --- |
| 题目阅读页与个人中心 | 只经由后端接口提交与读取；不接触供应商端点、请求头、Key 或系统提示词 |
| 网站后端业务层 | 鉴权、配置事务、可信题目快照、账号归属校验 |
| 进程内 AI 运行模块 | 固定目录、账号生成位、会话、流与停止；不访问业务数据库 |
| 模型层 | 按型号协议转换消息与流事件；不加载宿主资源 |

### 5.3 职责不变量

- 账号只取认证结果；配置、会话、检测、停止与关闭都校验账号归属。浏览器不能指定账号、Key 来源、端点、请求头或系统提示词。
- 请求级 Service / Repository 负责数据库读取与显式写事务：复制所需普通字段与可信快照后回滚读事务，再进行主密钥读取、线程解密或长时间等待，不把 ORM 对象传给生成任务。
- 应用生命周期统一管理运行模块、会话与活跃生成；导入或构造不发模型请求、不联网读取目录。
- 运行模块不接受任意文件路径、端点、请求头、系统提示词或工具定义。
- 首版只有一个提供业务请求的 worker：内存会话、互斥与失效记录不跨 worker 共享；热重载或重启会结束本地会话，不声称可恢复。
- 阻塞文件操作在线程中执行；本批不做图像转换与 SVG 渲染，不在主事件循环读取或解码图片。
- 题目图片只在业务层按受控上传目录读取，文件名、扩展名、单图字节与总字节都有硬上限；外链与非上传目录地址只按规则拒绝，不发起网络请求，浏览器不能指定路径、地址、账号或系统提示词。
- 术语约定：「图片」指题目素材（含内联 SVG 源码），「图像」指模型的图像输入能力，「图片数据」指从受控目录读取到的字节；「载荷」只用于配置修订与加密密文。

### 5.4 模型调用隔离

- 不加载宿主编排文件、Skill、扩展、模板、系统提示词、MCP、宿主凭据文件或模型配置；不启用文件、终端、自定义工具或资源发现。
- Key 只进入当前账号的私有发送边界与短生命周期内存，不写客户端持久化、全局变量、目录缓存或协议历史；显式传入 Key 与固定端点，禁止宿主或其他账号凭据兜底。
- 正常校验 HTTPS / TLS，不绕过证书、不向重定向地址继续携带认证、控制环境代理行为；不声称固定地址提供完整 DNS 重绑定防护。
- 咨询与检测不自动重试、不换型号、不摘要、不预热、不隐式联网。

### 5.5 账号、凭据与数据

- 每账号、每供应商一份加密 Key；缺省或空值只保留已有密文，不隐式删除；明文只在保存与发送边界短暂存在，不回传、不进日志、不写浏览器存储。
- 清除与检测都有独立确认，保存不自动检测；删除默认选择保留全部凭据，删除供应商只清必要的默认引用。
- 主密钥独立于业务数据库与 Git：仅首次明确保存新 Key 时允许补建，解密只读既有文件，缺失或损坏拒绝，不重建、不覆盖、不降级明文。轮换主密钥、删除本站配置与撤销上游 Key 是不同动作。
- 业务数据库由 Git 跟踪，历史密文随之保留；仓库内密文在缺少主密钥时不可解密，但删除当前记录不等于消除历史风险。
- 聊天、提问、回答、隐藏思考与题目图片数据不落库。

### 5.6 生成、停止与终态

- 每账号一个生成位，检测与咨询共用；忙碌时拒绝，不建设等待队列。
- 停止只取消原请求，结束放弃整个会话；收起只隐藏窗口，不停止生成，可能继续计费。生成中主动结束或切题须确认；离页与账号变化时清理。停止未确认时保留生成位并拒绝新生成，不以任务取消或关闭浏览器作为上游停止与费用撤销的证明。
- 只有真实成功的完整终态保留历史并允许追问；停止、失败、超时或断流放弃服务端会话，前端保留片段并标记为不完整。非成功终态后不再允许继续发送，须新建会话清空本次聊天后重新咨询；仅收起再展开不能恢复追问。
- 隐藏思考不进入公开增量、完整回答或日志。
- 首轮流事件前需要停止时以结束会话处理；迟到初始化或迟到结果不得开始生成。前端会话修订与请求标识阻止结束、切题后的迟到创建、流式增量、终态及停止错误污染新会话。

### 5.7 有界内存与单进程边界

内存会话、历史、事件与缓冲都有界（题目图片数据同样受张数、单图字节、单题总量与 SVG 源码长度上限约束）：容量只需保证当前少量并发会话与单次长回答可用，超限时明确拒绝，而不是静默截断、丢内容或淘汰安全保护。容量、超时与保留期的具体取值留到实现阶段按当次事实确定（见 6.3）。单进程内存机制不提供分布式一致性，也不撤回已发往上游的数据。

### 5.8 日志与隐私

日志只保留安全关联标识、耗时与状态，不记录认证头、明文 Key、密文、请求体、完整题目、提问、隐藏思考与图片内容、文件名及原始地址；未附带的图片只下发固定原因码，不下发地址。原始上游异常不得通过错误链、日志或响应泄露。AI 回答使用独立清洗策略，不运行模型 HTML 或脚本，远程资源进入 DOM 前受限。本地部署不等于离线：检测与咨询都会向供应商发送内容并可能产生费用，停止不撤销已发生的费用。

## 6. 可行性限制、风险与待定问题

### 6.1 可行性限制

- 单进程设计：内存会话、生成位与失效记录不跨 worker 共享，不提供分布式一致性，不可分布式扩展；热重载与重启会丢会话。
- 模型目录为随应用发布的冻结集合，无法联网刷新，新增或变更型号需要改动注册表。
- 上游已发送的数据与已发生的费用不可撤回；停止只作用于当前请求。
- 图片链路只支持本站上传目录内的位图与内联 SVG 源码文本：外链图片不下载、SVG 不渲染成位图、不做图像压缩；图片属于会话固定上下文，会随历史每轮重发，追问会重复消耗图像 token 与费用。
- 本地部署不等于离线运行。

### 6.2 风险与不可逆点

- 旧 Node 实现已删除且无副本：回滚不能只重开端口，需重新获取对应 SDK 并重建服务源码与启动方式；不同时启用两套生成路径。
- 模型清单是冻结内容，原目录已随旧实现删除，无法再自动生成，更新只能手工维护或重新生成。
- 回答区与题目区是两套渲染路径：一套使用独立白名单与自维护样式，一套使用共享白名单；公式与 Markdown 能力需分别维护，相关依赖升级要同时核对两处。
- 数据库、备份与主密钥文件原样保留，不自动还原、清理或重建。
- 可停用 AI 运行层而不影响普通读题。

### 6.3 待定问题
