# AI 题目咨询模块开发设计

> 状态：已实施（FastAPI 进程内 Python），实际验证边界见第 7 节。
> 本文只保留设计框架、关键决策与必须保持的约束；协议字段、逐型号元数据、容量常数、接口逐字段定义等实现细节由代码承载（见第 3 节指向），开发阶段以当次事实为准。
> 本文是记录与约束，不构成源码修改、依赖安装、数据库操作、服务启停、测试或真实模型调用的执行授权。

## 1. 目标与范围

### 1.1 业务目标

- 真题、模拟题、改编题阅读页提供“AI 咨询”；不覆盖管理端，不建设通用聊天首页。
- 个人中心按供应商管理 API Key 与独立启用状态；默认咨询型号与凭据分开保存，不因浏览或切换供应商自动改选型号。
- 保存凭据、查询目录、保存默认选择与真实检测是相互独立的操作；保存或打开页面不自动调用模型；目录收录不代表当前账号有调用权限。
- 题目上下文包含题干、A-D 选项、参考解析、科目与分类；允许参考解析透露答案并在面板明确提示，参考解析不是绝对正确的系统指令。
- 提供流式回复、连续追问、停止与关闭；只有用户明确发送或确认检测才发起生成，不自动换模型、重试、摘要压缩或预热。
- 聊天只存在于服务器与页面内存：不写数据库、localStorage 或 sessionStorage，刷新、关闭、服务重启后不可恢复。
- 打开咨询前退出题目全屏 / 沉浸，关闭后不自动恢复；退出全屏失败时提示手动退出，不打开咨询也不调用模型。

### 1.2 本批边界

- 已完成：把独立 Node AI 服务与 Pi JavaScript SDK 调用层替换为 FastAPI 进程内的 Python 运行模块；Vue / Vite 前端技术栈不变，不新增 AI 监听端口或常驻服务。
- 供应商注册表当前只收录 OpenCode Go（用户确认）。数据模型、加密凭据、双修订与前端选择器保留多供应商能力：增加供应商只需追加注册表项，不改架构。
- 保留现有数据库、已保存配置与加密主密钥；不重建表、不添加迁移链、不重置凭据。
- 未包含（后续另报清单）：题目页聊天入口、聊天面板、安全回答渲染、图片 / SVG 链路。

### 1.3 明确不做

聊天历史同步、同账号多套默认配置档案、自定义供应商端点、订阅 OAuth、宿主 IAM / ADC / 云账号凭据发现、普通用户上传图片、外链图片抓取、独立讲解过程图自动携带、OCR、联网搜索、题库检索、文件 / 终端 / Skill / MCP 工具、模型回写题目。

按本地单 FastAPI worker 设计：不建设多 worker 配额协调、独立准备任务系统、跨服务容量握手、通用元数据平台、自研 DNS 拨号、会话级连接池、常驻图像进程池或完整系统沙箱。

## 2. 调用链与职责边界

```text
Vue 个人中心 / 后续阅读页
  → FastAPI：网站鉴权、配置事务、可信题目快照
  → 进程内 AI 运行模块：固定目录、账号生成位、会话、流与停止
  → 模型层：按型号协议转换消息与流事件
  → 当前用户选择的供应商与型号
```

职责不变量：

- 账号只取认证结果；配置、会话、检测、停止与关闭都校验账号归属。浏览器不能指定 `user_id`、Key 来源、端点、请求头或系统提示词。
- 请求级 Service / Repository 负责数据库读取与显式写事务：复制所需普通字段与可信快照后回滚读事务，再进行主密钥读取、线程解密或长时间等待，不把 ORM 对象传给生成任务。
- 应用 lifespan 统一管理运行模块、会话与活跃生成；导入或构造不发模型请求、不联网读取目录。
- 运行模块不接受任意文件路径、端点、请求头、系统提示词或工具定义。
- 首版只有一个提供业务请求的 worker：内存会话、互斥与失效记录不跨 worker 共享；热重载或重启会结束本地会话，不声称可恢复。
- 阻塞文件操作在线程中执行；后续图像转换使用一次性普通子进程，不在主事件循环解码或渲染 SVG。

复用与承载位置：

| 职责 | 位置 |
| --- | --- |
| 三类题目详情 | `ExamQueryService` / `MockQueryService` / `AdaptationQueryService.get_by_id()` |
| 认证 | `modules/auth/dependencies.py`，不另建认证体系 |
| AI 业务与持久化 | `modules/ai/`（Model、Repository、配置、可信快照） |
| 进程内运行模块 | `modules/ai/runtime/`：目录注册表、模型构造、会话与生成位、门面、公开错误 |
| 应用生命周期 | `main.py` lifespan |
| 个人模型服务前端 | `AiSettings.vue` / `AiProviderSettings.vue` / `AiModelPicker.vue` / `api/ai.ts` |
| 后续咨询弹层 | 复用 `ResponsiveDialog.vue`，三类题目共用一套面板 |
| 回答渲染 | 复用 Markdown / 公式能力，但使用独立安全策略，不改共享题目白名单 |

## 3. 关键决策与依据

| 决策 | 结论 | 依据与影响 |
| --- | --- | --- |
| 运行位置 | AI 在 FastAPI 进程内执行，不新增端口、不启停独立服务 | 消除跨服务失效通知的送达依赖与旧内部凭据；代价是单进程内存边界与重启即丢会话 |
| 供应商范围 | 注册表只收录 `opencode-go`，固定端点、单一 API Key | 用户确认；数据模型与前端保留多供应商能力，扩展只需追加注册表项 |
| 协议与型号元数据 | 由服务端注册表承载，按型号协议分别适配，不一律走 Chat Completions | 公共目录没有协议、地址与 compat 字段，无法替代；细节见 `runtime/go_catalog.py` |
| 模型层 | 使用底层模型请求接口 + 自建 SDK 客户端，显式关闭重试、环境代理与重定向 | 需要逐参数控制；不启用 Agent 编排、工具或宿主资源加载。细节见 `runtime/model_factory.py` |
| 目录来源 | 随应用发布的冻结注册表；不接入联网刷新 | 协议字段只能来自服务端注册表；来源取值与前端文案已同步，更新方式见第 6 节 |
| 旧载荷防护 | 双修订 + 固定登记期限 + 进程内失效登记与取消 | 必须在额度消耗前拒绝旧载荷；细节与常数见 `runtime/session.py` |
| 图片链路 | 本批不实现，方法待定 | 需先核定位图库、SVG 渲染器与字体资产 |

## 4. 必须保持的约束与不变量

### 4.1 模型调用隔离

- 不加载宿主 AGENTS、Skill、扩展、模板、SYSTEM、MCP、`auth.json` 或模型配置；不启用文件、终端、自定义工具或资源发现。
- Key 只进入当前账号的私有发送边界与短生命周期内存，不写客户端持久化、全局变量、目录缓存或协议历史；显式传入 Key 与固定端点，禁止宿主 / 其他账号凭据兜底。
- 正常校验 HTTPS / TLS，不绕过证书、不向重定向地址继续携带认证、控制环境代理行为；不声称固定地址提供完整 DNS 重绑定防护。
- 咨询与检测不自动重试、不换型号、不摘要、不预热、不隐式联网。

### 4.2 账号、凭据与数据

- 每账号、每供应商一份加密 Key；缺省 / 空值只保留已有密文，不隐式删除；明文只在保存与发送边界短暂存在，不回传、不进日志、不写浏览器存储。
- 清除与检测都有独立确认，保存不自动检测；删除默认选择保留全部凭据，删除供应商只清必要的默认引用。
- 主密钥独立于业务数据库与 Git：仅首次明确保存新 Key 时允许补建，解密只读既有文件，缺失或损坏拒绝，不重建、不覆盖、不降级明文。轮换主密钥、删除本站配置与撤销上游 Key 是不同动作。
- 业务数据库由 Git 跟踪，历史密文随之保留；仓库内密文在缺少主密钥时不可解密，但删除当前记录不等于消除历史风险。
- 聊天、提问、回答与隐藏思考不落库。

### 4.3 生成、停止与终态

- 每账号一个生成位，检测与咨询共用；忙碌时拒绝，不建设等待队列。
- 停止只取消原请求，关闭放弃整个会话；停止未确认时保留生成位并拒绝新生成，不以 `Task.cancel()` 或关闭浏览器作为上游停止与费用撤销的证明。
- 只有真实成功的完整终态保留历史并允许追问；停止、失败、超时或断流放弃会话，片段标记为不完整。
- 隐藏思考不进入公开增量、完整回答或日志。
- 首轮流事件前需要停止时以关闭会话处理；迟到初始化或迟到结果不得开始生成。

### 4.4 有界内存与单进程边界

内存会话、历史、事件与缓冲都有界，超限明确拒绝而不是静默截断、丢内容或淘汰安全保护。容量、超时与保留期的具体值由 `runtime/session.py` 常量承载；调整需明确影响并获准验证。单进程内存机制不提供分布式一致性，也不撤回已发往上游的数据。

### 4.5 日志与隐私

日志只保留安全关联标识、耗时与状态，不记录认证头、明文 Key、密文、请求体、完整题目、提问或隐藏思考；原始上游异常不得通过错误链、日志或响应泄露。AI 回答使用独立清洗策略，不运行模型 HTML 或脚本，远程资源进入 DOM 前受限。本地部署不等于离线：检测与咨询都会向供应商发送内容并可能产生费用，停止不撤销已发生的费用。

## 5. 验收条件

| 场景 | 成功标准 |
| --- | --- |
| 纯 Python 部署 | 不启动 Node 服务、不监听旧端口、不读取旧内部 Token 时，设置与文本后端仍可工作；不影响 Vue / Vite |
| 供应商与目录 | 支持声明与注册表一致；离线浏览不联网；供应商标识不符直接拒绝，不猜测协议 |
| 凭据与默认选择 | Key 加密且不回传、不进日志；首次必填、空值保留；清默认保留 Key；不自动选型号或检测 |
| 主密钥 | 原文件可继续解密；缺失 / 损坏不重建覆盖；不改变加密版本或旧数据 |
| 账号隔离 | 不能查询、调用、检测、停止或关闭其他账号的配置与会话，不回退到其他账号 / 宿主凭据 |
| 旧修订与期限 | 失效先到、旧请求后到仍不能生成；过期与保护容量满拒绝；解密不刷新期限 |
| 生成与检测互斥 | 检测与咨询共享账号位，重复请求不执行；未确认停止不释放生成位 |
| 模型调用副作用 | 无工具、资源发现、聊天落盘、默认重试、回退、摘要、预热或隐式联网；TLS 正常，错误安全 |
| 文本、多轮与协议 | 三类题目快照正确；隐藏思考不公开；不把单一协议成功当作全部协议通过 |
| SSE 与终态 | 成功为非空完整回答且只有唯一终态；断流、取消或异常片段不误报成功 |
| 取消与退出 | 初始响应前取消、检测断线、流未迭代即结束、配置变化、超时与应用退出都清理原任务 |
| 后续图片与阅读页 | 仅本题授权素材并真实规范化送入模型；阅读页全屏、输入法、公式、导航与账号清理不被破坏 |

上述是验收标准；各场景的实际验证状态见第 7 节，图像效果按具体供应商、型号与实际附图单独验证。

## 8. 风险与回滚

- 旧 Node 实现已被删除且未提交、无副本：回滚需重新获取对应 SDK 并重建 Node 服务源码与启动方式，不能只重开端口；不同时启用两套生成路径。
- 模型清单为冻结快照，原目录已随 Node 删除，无法再自动生成，更新只能手工维护或重新生成。
- 单进程边界：多 worker、重启与热重载会丢失会话，不可分布式扩展。
- 数据库、备份与 `master.key` 原样保留，不自动还原、清理或重建；回滚不撤回已发往供应商的数据与费用。
- 纯 Python 运行层可停用 AI 而不影响普通读题。
