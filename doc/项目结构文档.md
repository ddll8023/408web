### frontend/src/ 根目录与全局样式

**目录职责**：承载 Vue 根组件、应用初始化入口和全局 CSS；业务代码分布在 API、组件、组合式函数、Store、路由和视图子目录。

**样式覆盖范围**：`frontend/src/views/` 下当前 17 个页面均直接使用 Tailwind CSS 工具类；公共组件整体采用混合方式，Markdown 编辑器/预览器和部分交互组件仍保留第三方 CSS 或局部 CSS。全局导航高度、可视页面高度、滚动条槽位和响应式断点约定集中在 `frontend/src/styles/tailwind.css`：全站只用 420/640/768/1024/1280 五档断点，自定义媒体查询统一写 `max-width: 档位 − 1`（639/767/1023/1279）以与 `sm:/md:/lg:/xl:` 互补。公共下拉组件的视觉令牌集中在 `frontend/src/styles/dropdown.css`，不能将“全部页面使用 Tailwind”理解为“所有组件样式完全由 Tailwind 独占”。

- `frontend/src/main.ts` — **功能**：创建 Vue 应用，注册 Pinia、Router 和 FontAwesome，加载 KaTeX、全局与公共下拉样式并预加载科目 Store；**优先读取场景**：修改全局插件、图标库、样式导入或应用初始化顺序。
- `frontend/src/App.vue` — **功能**：渲染全局 `Navigation`、路由视图和 `keep-alive` 布局，通过 `main-content with-nav` 类为已登录导航预留顶部高度，并在登录/注册页隐藏导航；**优先读取场景**：修改全局页面框架、导航占位方式、导航显示条件或路由缓存行为。
- `frontend/src/styles/tailwind.css` — **功能**：引入 Tailwind v4 并通过 `@config` 加载 JS 配置，定义两组语义令牌——品牌与中性色（`--brand-accent` / `--brand-accent-hover` / `--brand-accent-deep` / `--brand-surface` / `--brand-line` / `--brand-ink` / `--brand-ink-soft` / `--brand-ink-mute`）和内容主题色（`--theme-exam-*` 蓝 / `--theme-mock-*` 绿，按 accent / strong / icon-fg / icon-bg / surface / surface-soft / surface-badge / border / subtitle / soft-fg 角色命名），改色只改这一处；另定义全局重置、`--app-nav-height`/`--app-page-height` 变量、`.app-viewport-page`、`.scrollbar-stable`、`scrollbar-gutter`、窄屏输入字号和 KaTeX 样式；**优先读取场景**：修改品牌色与主题色、导航高度、满高页面尺寸、滚动条稳定性、Tailwind 全局层或 Markdown/公式基础样式。组件类名用 `text-accent`/`bg-surface`/`text-exam-strong` 等工具类，scoped CSS 直接用 `var(--brand-*)`；需要半透明品牌色时统一用 `bg-accent/12` 或 `color-mix(in srgb, var(--brand-accent) 12%, transparent)`，不再写 `rgba(139,111,71,…)` 字面量；未令牌化的长尾颜色（分类统计与图标装饰用的 Ant 蓝绿 `#73d13d`/`#52c41a`/`#40a9ff`/`#1890ff`、统计页蓝 `#5D88AE`、标题深墨色 `#33404A`/`#27333d`/`#3f4b54`、一次性中性色 `#F5EFE6`/`#eadfd4`/`#DCCBB5` 等）有意保留字面量，避免为一次性取值造令牌。
- `frontend/src/styles/dropdown.css` — **功能**：定义 Select、InputSelect、MultiSelectCascader、WheelPicker 和 Dropdown/DropdownItem 共用的下拉视觉令牌（其 `--dropdown-accent` / `--dropdown-accent-soft` 引用 `--brand-accent`，其余表面与边框令牌保持独立）、触发器、面板、选项状态、空状态、滚动条和动效；**优先读取场景**：修改公共下拉风格或排查组件间样式不一致。
- `frontend/src/vite-env.d.ts` — **功能**：声明 Vite 客户端与可选 `VITE_API_BASE_URL` 环境变量；**优先读取场景**：调整前端构建环境变量类型。
- `frontend/src/shims.d.ts` — **功能**：按实际调用声明 Markdown 编辑器/预览插件接口，并为没有官方类型的 `markdown-it` 提供最小模块声明（安装 `@types/markdown-it` 后应删除该声明）；**优先读取场景**：排查编辑器实例、插件或 `markdown-it` 类型缺失。
