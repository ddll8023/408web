# 答案解析风格规范

本题库 `answer` 字段的答案与解析统一遵循本规范。规范同时约束三条产出路径：AI 生成答案、手工录入、改编题命题。任何一处修改都必须同步其余两处，否则会出现同一题库内风格分叉。

## 适用范围

- 适用于真题、模拟题、改编题三类题目的 `answer` 字段。
- 只规定答案与解析的组织方式和表达形式，不规定题干、选项、分类、难度等字段。
- 求解正确性、是否需要图示的判断责任在人，本规范只保证结构可机械识别。

## 核心原则

答案解析结构是**封闭模板**：只有下面两种合法版式，不允许自行增减小节、改名或省略规定小节。

解析只写该小问的求解依据与推导。不写背景介绍、考点罗列、错误归纳、知识延伸、命题说明。

## 选择题版式

```
**正确答案：C**

**解析**

……

**选项辨析**

- **A**：判断与理由。
- **B**：判断与理由。
- **C**：判断与理由。
- **D**：判断与理由。
```

三节均为必备，缺一即不合格。

- 首行固定 `**正确答案：C**`，`C` 替换为实际答案。
- 原题明确多选时，字母按 A–D 顺序连续排列，如 `**正确答案：ABD**`，不得写作 `**正确答案：DBA**`。
- 第二节固定 `**解析**`，写清判断依据。涉及公式、数值或状态检查时给出关键公式与代入，不得只写一句结论或只复述题干。
- 第三节固定 `**选项辨析**`，必须有实质内容，不得空置或只重复选项原文。写法按选项形式分两类：

### 独立陈述型选项

A–D 各自是一句独立判断时，按 A、B、C、D 逐项说明成立或不成立的理由，每项独占一行：

```
- **A**：判断与理由。
- **B**：判断与理由。
```

### 组合排序型选项

选项由题干编号项组合或排序而成时（如 `A. ②→③→①→④`、`B. I、II、III`），逐项复述 A–D 没有意义，改为：

1. 按题干编号项（①②③④、I/II/III 等）逐条判断真伪，或确定它们之间的先后顺序；
2. 据此得出正确组合或排列；
3. 指明对应选项。

### 其他约束

- 纯数值题不重复完整计算，但仍须逐项或逐编号项给出结论性判断。
- 不编造干扰项的设计原因。

## 主观题版式（有明确小问）

```
**答案**

(1) 结论一

(2) 结论二

(3) 结论三

**(1) 解析**

……

**(2) 解析**

……

**(3) 解析**

……
```

- 首行固定 `**答案**`。
- 其下按原题小问编号**逐条列出全部结论**，每条只写结果、关键数值与单位，**不展开推导**。答案区应能脱离解析单独阅读。
- 全部结论写完后，空行起按同一套编号逐条展开，每条以独立加粗行 `**(n) 解析**` 开头。
- 编号必须与原题完全一致：原题用（1）就写（1），原题用 ① 就写 ①，不得重编号、不得跳号、不得合并小问。
- 一个小问内若涉及多个求解对象，直接在该小问解析内分点说明，不另开新小节。

## 主观题版式（无明确小问）

```
**答案**

最短路径长度为 $18$，路径为 $v_1 \to v_3 \to v_4 \to v_6$。

**解析**

……
```

原题没有小问编号时，不自行编号，`**答案**` 后直接给结论，空行接 `**解析**`。

## 禁止项

出现以下任一内容即视为不合格，必须重写。

**禁止的加粗小节**

`**核心依据**`、`**解题过程**`、`**图示分析**`、`**易错点**`、`**理由**`、`**结论**`、`**分析**`、`**原因**`、`**注意**`、`**修正为**`，以及任何其他自行命名的小节名。

除规定小节外，加粗只能用于句中的概念强调，不得独占一行充当小标题。

**禁止的 Markdown 结构**

- `#`、`##`、`###` 等 Markdown 标题，一律改用独立加粗行小标题。
- `---` 等分隔线。
- `*解析*` 之类斜体小标题。

**禁止的内容倾向**

- 与结论无关的背景铺垫、考点清单、知识延伸。
- 用"显然""由公式可得""运行算法可知"跳过关键过程。
- 重复堆叠思路、过程、结论。
- 罗列"本题考点""命题意图""易错提醒"等命题侧内容。

## 公式规范

- 行内变量、下标、复杂度、简短等式用 `$...$`。
- 重要公式、代入过程、计算结果用 `$$...$$`，`$$` 起止各占一行，前后留空行。
- 数学内容只能使用 `$...$` 与 `$$...$$` 定界。禁用 `\(...\)`、`\[...\]`、`equation` 等环境。
- 禁用 Unicode 或 HTML 上下标，一律用 LaTeX 写法。
- 禁用 `/` 表示分式，分式一律用 `\frac`。
- 使用规范 LaTeX 命令：`\frac`、`\lfloor`、`\lvert`。
- 公式不放反引号、不放普通代码块；同一公式不附纯文本副本。
- 数学下标的下划线前不加反斜杠。
- 不默认使用 `\boxed`、`\color`、`\mathbf`、`\boldsymbol`、`\displaystyle`、`\dfrac`、`\tfrac` 制造另一种视觉风格。
- `\text{...}` 只用于语义必需的短中文下标或分段条件，如 `$[x]_{\text{补}}$`；不把整段解析塞进 `\text{...}`。
- 解释、条件说明和结论以普通中文放在公式外；中文句末标点一般放在行内定界符外；独立公式不附中文句号。
- 详细排版细则见 [公式排版规范](./公式排版规范.md)。

## SVG 规则

**触发条件**

仅当题目**明确要求作图**时才提供 SVG，例如要求画数据结构、结构关系、状态转移、排列形态、操作前后结构变化等。

题目未要求作图时，不因结论涉及连接、层级、方向、位置、包含或依赖关系而额外画图，也不用图示替代文字推导。

**位置**

图形紧跟其所解释的那段小问解析，不单独设小节。题目明确要求作图时，图示不可省略。

**写法**

- 使用完整的 ` ```svg ` 代码块，根元素必须声明 `xmlns='http://www.w3.org/2000/svg'` 和 `viewBox`。
- 仅使用 `svg`、`g`、`line`、`path`、`circle`、`ellipse`、`rect`、`polygon`、`polyline`、`text`、`tspan`。
- 明确坐标、字号、填充、线条颜色及线宽；属性优先用单引号。
- 箭头使用线段加三角形。
- 先画连线，再画对象和标签；留白、不穿字、不重叠、不超出 `viewBox`。
- 不只靠颜色传达信息，同时用标签、位置或线型区分。
- 图中文字用普通中文或 Unicode；复杂公式写在图外。

**禁止**

脚本、事件处理器、动画、`foreignObject`、`style`、外部字体、外部资源、链接、图片、Base64、`url()`、`defs`、`marker`。不得把整个 SVG 转成 `&lt;svg&gt;` 文本。

**严谨性**

- 图形必须展示题目要求的结构、关键关系、阶段或约束冲突，不能只是装饰框或文字容器。
- 多种合法结构只画一种时，注明"示例"。
- 证明"不可能"必须有约束冲突或充分论证，不能仅凭未找到实例。
- 未按比例的图不能用于推断未经计算的长度、面积或角度。
- 图形须与题干、正文、公式和结论一致。

## 表格与排版

- 表格用于属性比较、多轮精确数据、状态记录，尽量两至四列。
- 长解释和块级公式放在表外，单元格只用行内公式。
- 数学竖线用 `\lvert`、`\rvert`、`\mid`，避免与表格分列符冲突。
- 顺序操作使用有序列表；定义、原因、条件和结论用短段落。
- 加粗小标题、段落、列表、表格、代码块与块级公式之间留空行。
- 每段一个主要观点，通常一至三个短句。
- 不用表格和长文重复同一内容。

## 降级处理

- 题面用 `[图 N]` 标识图形，只能解读实际附带的图片或正文中的 SVG 源码；标记为未附带的图不得猜测内容或假装看过。
- 缺失材料或条件不足以可靠求解时：
  - 选择题**不输出**正确答案首行；
  - 主观题以"无法可靠求解："开头，写明缺口。
- 此类答案供人工辨识，不可直接采用。
- 不编造答案，不声称已运行代码或验证。

## 示例

**选择题**

```
**正确答案：A**

**解析**

分区分配通过界地址寄存器实现越界保护：访问逻辑地址时硬件检查
$0 \le \text{逻辑地址} < \text{限长}$，或检查物理地址是否落在分区的上下界之间，越界则产生越界中断。

**选项辨析**

- **A**：成立。分区分配以基址—限长寄存器或上下界寄存器实现边界检查，即界地址保护。
- **B**：不成立。程序代码保护不是分区分配的主要保护措施。
- **C**：不成立。数据保护范围过于笼统，分区保护的核心是地址空间边界检查。
- **D**：不成立。栈保护针对栈区越界，不是分区分配方式的主要机制。
```

组合排序型选项的辨析写法：

```
**正确答案：B**

**解析**

……

**选项辨析**

① 成立，进程创建后即处于就绪态。
② 不成立，就绪态进程只缺 CPU，不等待 I/O。
③ 成立，……
④ 不成立，……

由 ①③ 成立、②④ 不成立可得正确顺序为 ②→④→③→①，对应选项 B。
```

**有小问的主观题**

```
**答案**

(1) 每行 Tag 占 20 位，LRU 位占 3 位，无修改位。

(2) 数据 Cache 缺失次数为 64 次。

**(1) 解析**

数据区容量只计数据，不含 Tag、有效位与 LRU 位。地址按字节编址，
主存块大小 $64\mathrm{B}$，故块内偏移占 6 位。

$$行数=\frac{32\mathrm{KB}}{64\mathrm{B}}=512,\qquad 组数=\frac{512}{8}=64$$

$$\text{Tag}=32-6-6=20$$

8 路组相联采用 LRU，每行需记录该行在组内 8 行中的使用顺序：

$$LRU位=\log_2 8=3$$

**(2) 解析**

……
```

**无小问的主观题**

```
**答案**

最短路径长度为 $18$，路径为 $v_1 \to v_3 \to v_4 \to v_6$。

**解析**

从初始顶点开始，每轮选择离当前顶点最近且未加入的顶点……
```

## 同步位置

修改本规范时，以下三处必须同步，否则规则只在部分路径生效：

| 位置 | 作用 |
| --- | --- |
| `backend-fastapi/src/web408/modules/ai/answer_prompt.py` | AI 生成答案的系统提示词，`ANSWER_SYSTEM_PROMPT` |
| `docs/题目/录入提示词.md` 的「答案组织」与「SVG 触发与论证」 | 手工录入与外部 GPT 录入的指令 |
| `docs/题目/改编提示词.md` 的「解析风格」与「图表与公式」 | 改编题命题指令 |

前端 `frontend/src/utils/aiAnswer.ts` 的 `answerStructureError` 是这套规范的机械校验实现，白名单小节（选择题 `解析`、`选项辨析`；主观题 `答案`、`解析`）与逐小问标题正则 `**(n) 解析**` 必须与上面保持一致。校验不通过时「采用新答案」按钮不可用。
