# 408Web 项目结构

本页是 Agent 的代码导航：先建立全局结构，再读目标模块与其引用的公共记录，不必逐篇加载全部文档。源码路径默认相对仓库根；文档链接相对本文。

## 项目概览

408 考研题库与命题工具，包含阅读端、管理端、分类统计、出题工作台和 AI 题目咨询。

- **前端**：Vue + TypeScript SPA，Vue Router、Pinia、Tailwind、自研组件；Markdown 与公式渲染使用 v-md-editor、markdown-it、KaTeX 和 XSS 过滤。
- **后端**：FastAPI + Pydantic，SQLModel 异步访问 SQLite；业务按模块纵向组织。AI 通过 PydanticAI 调用模型，在同一后端进程内运行。
- **资源**：业务数据存 SQLite，图片存本地文件；AI 凭据密文入库，主密钥独立保存，咨询会话只存内存。

具体依赖与版本以 `frontend/package.json`、`backend-fastapi/pyproject.toml` 为准。

## 运行入口与主链路

```text
浏览器中的 Vue SPA
  ├─ /api/* → FastAPI → 业务模块 → SQLite / 本地图片
  │                      └─ AI 运行时 → 外部模型服务
  └─ /uploads/images/* → FastAPI 静态文件
```

| 入口 | 定位与职责 |
| --- | --- |
| 前端装配 | `frontend/index.html` → `frontend/src/main.ts` → `frontend/src/App.vue` → `frontend/src/app/layouts/AppShell.vue`；注册路由、Pinia、图标与样式，承载导航、布局、路由缓存和全站 AI 窗口 |
| 页面与权限导航 | `frontend/src/router/index.ts`：页面注册、路由元信息、登录与管理员守卫；`frontend/src/app/layouts/` 承载全局、管理端与阅读页布局 |
| 后端装配 | `backend-fastapi/src/web408/main.py`，ASGI 入口 `web408.main:app`；挂载静态文件、中间件、异常处理与 API |
| 后端路由 | `backend-fastapi/src/web408/api/router.py`：聚合业务模块；默认前缀 `/api`，另有根路径与 `/health` 健康检查 |
| 进程生命周期 | 后端 `lifespan` 补建缺失表并启动 `AiRuntime`；退出时关闭 AI 会话与数据库引擎，无独立 AI 服务或端口 |

典型请求：页面 → `frontend/src/api/` 请求封装 → 后端模块 `router.py` → 查询／写入服务 → repository → 数据库；响应由 mapper／schema 转换后返回页面。模块可以有专用服务，不强制所有文件采用同一分层。

开发前端端口配置为 `7784`，后端默认 `7785`。`frontend/vite.config.ts` 将 `/api`、`/uploads` 代理到 `localhost:7785`；预览复用代理，但未显式设置端口，不能按开发端口理解。浏览器未配置 `VITE_API_BASE_URL` 时走同源请求，配置后直连目标后端并受 CORS 约束。

后端以 `backend-fastapi/` 为工作目录：`.env` 及默认 `data/`、`uploads/`、`logs/` 均依赖此目录。根目录 `startup-backend.bat`、`startup-backend.command`、`start-frontend.bat`、`start-frontend.command` 是开发启动入口，不是发布产物。

## 代码地图与任务导航

| 前端 | `components/basic/`、`components/business/` | 无业务语义的基础组件与业务组件；共享能力见公共记录 |

| 前端 | `stores/`、`composables/` | 全局登录／科目状态与可复用交互、取数逻辑 |
| 前端 | `utils/`、`constants/`、`shared/responsive/`、`styles/` | 内容转换、领域常量、统一响应式能力与全局样式 |
| 后端 | `modules/` | 业务路由、schema、服务、repository、模型；跨模块读取通过各域公开服务协作 |
| 后端 | `modules/question_content/` | 三类题目共用的选项校验与 JSON 序列化，无独立路由或业务表 |
| 后端 | `api/`、`core/`、`middleware/` | 路由与会话依赖、配置、安全、异常、日志、全局 CORS |

| 后端 | `integrations/` | 本地文件存储与 AI 主密钥适配，不拥有业务用例 |

### 业务模块

模块是跨前后端的逻辑能力，不等于一个目录。后端实现在 `backend-fastapi/src/web408/modules/`，`custom-category` 对应源码目录 `custom_category`；`compose` 是纯前端组合，没有同名后端模块。

| 模块 | 任务与边界 | 继续读取 |
| --- | --- | --- |
| `auth` | 注册、登录、当前账号与管理员校验；个人中心、收藏及 AI 设置入口 | [认证与账号](modules/auth.md) |
| `catalog` | 科目、章节、大纲分类树、分类计数与改名同步 | [目录与分类管理](modules/catalog.md) |
| `custom-category` | 与大纲并行的自定义分类树，供真题挂载和筛选 | [自定义分类](modules/custom-category.md) |
| `exam` | 真题按年份／分类浏览、编辑、查重及过程图片关联 | [真题](modules/exam.md) |
| `mock` | 模拟题浏览与维护、出题状态、答错次数 | [模拟题](modules/mock.md) |
| `adaptation` | 改编题维护、来源真题引用、占用提示与出题状态 | [真题改编题](modules/adaptation.md) |
| `reporting` | 真题分类统计与 Markdown／Excel 导出；后端路由挂在 `/api/exam`，不要仅按 URL 归入 exam | [统计与导出](modules/reporting.md) |
| `media` | 图片上传、资源列表、引用扫描与未引用文件清理 | [图片资源](modules/media.md) |
| `ai` | 个人供应商与模型设置、显式检测、流式咨询、管理员答案生成 | [AI 题目咨询](modules/ai.md) |
| `compose` | 分类取题、临时出题篮、复制／导出、出题标记；界面“章节树”实际使用大纲分类，并非 `/api/chapter` | [出题工作台](modules/compose.md) |

[公共记录](modules/shared.md)集中定位题目内容契约、Markdown／公式渲染、复制导出、请求传输、基础组件、全局外壳、阅读导航与管理表格。跨题型或跨页面问题先查对应共享能力，不在某个业务模块重复实现。

## 关键约束与状态归属

- **接口契约**：业务接口统一 POST，包含查询；普通 JSON 响应使用 `{code,message,data}`。`frontend/src/api/request.ts` 负责 Bearer 注入、信封检查与响应字段转 camelCase；下载保留二进制响应，AI SSE 由 `frontend/src/api/aiSession.ts` 使用 fetch 独立消费，不能套用普通 JSON 拦截器。
- **授权边界**：前端路由守卫负责导航，实际账号与管理员校验在后端 auth 依赖；登录态由 `frontend/src/stores/auth.ts` 管理，Token 与用户信息保存在 localStorage。
- **事务边界**：`backend-fastapi/src/web408/database/connection.py` 为每请求提供独立异步会话，不隐式提交；写用例显式提交。启动 `create_all` 只补建缺失表，不迁移已有表结构。
- **分类不是 ID 关联**：题目分类以名称数组序列化到 JSON 文本列；改名必须回写引用题目的标签，移动分类不改变标签。大纲分类涉及三类题目，自定义分类用于真题；修改需同时关注分类域、题目域与共享序列化。
- **图片关联不等于文件**：题目 Markdown 与真题过程图片共享 `uploads/images/`；删除过程图片只解除数据库关联，物理文件由 media 的引用扫描与未引用清理管理。
- **阅读状态与滚动**：阅读页使用路由 keepAlive、共享导航和滚动容器；分类阅读会全量取题以生成完整大纲。分页、分组、跳转或布局问题需同时看目标页面与公共记录的阅读导航部分。
- **AI 生命周期**：会话由后端重新读取题目快照后创建，创建本身不调用模型；发送才调用外部服务。停止针对本轮请求，关闭释放会话；进程重启会话丢失，路由或账号变化时前端清理窗口。答案生成只回填编辑草稿，不直接保存题目。

| 状态／资源 | 权威维护位置 | 持久化边界 |
| --- | --- | --- |
| 业务记录、出题标记、答错次数、AI 账号配置 | 各模块 `models.py` 与写入服务 | SQLite，默认 `backend-fastapi/data/web408.db`；出题标记与答错次数独立于题目主体保存 |
| 图片文件 | media 服务与 `backend-fastapi/src/web408/integrations/local_file_storage.py` | `UPLOAD_DIR`，默认 `backend-fastapi/uploads/images/`，通过 `/uploads/images/` 访问 |
| AI API Key 与主密钥 | `backend-fastapi/src/web408/modules/ai/key_cipher.py`、`backend-fastapi/src/web408/integrations/ai_local_secrets.py` | API Key 密文入库；主密钥在系统用户私有目录，须独立于数据库保存 |
| AI 咨询会话 | `backend-fastapi/src/web408/modules/ai/runtime/session.py` | 仅后端进程内存，不落库、不落盘 |
| 收藏、Markdown 图片显示尺寸 | 前端对应 composable | 浏览器 localStorage，不随账号跨设备同步 |

## 配置与资料入口

- **前端**：`frontend/package.json` 管依赖与脚本；`frontend/vite.config.ts` 管别名、开发与预览代理；`frontend/tsconfig.app.json`、`tsconfig.node.json` 管应用与工具配置的类型边界。应用启用 strict，不混入 JavaScript；PostCSS／Tailwind 配置仍是独立工具文件。主题与语义样式入口为 `frontend/src/styles/tailwind.css`。
- **后端**：`backend-fastapi/pyproject.toml` 管依赖与 uv_build 打包，包名 `web408`，源码根 `src/`，采用隐式命名空间包；`backend-fastapi/.env.example` 列出环境变量，实际解析见 `backend-fastapi/src/web408/core/config.py`。AI 运行参数由 `AiConfig` 固定，不从环境变量覆盖，账号配置由个人设置维护。
- **组件与内容规范**：[组件清单](../frontend/src/components/组件列表文档.md)定位组件用途；[题目规范目录](题目/)保存分类白名单、公式排版、答案解析与录入／改编提示词。
- **其他资料**：[README](../README.md)说明安装与使用；`后续开发任务.md` 是计划，不代表已实现结构；`.agents/memory/INDEX.md` 是项目技术约定与历史问题入口，不属于业务实现。
- **读取范围**：本地图覆盖仓库内前后端与装配关系；依赖目录、构建产物和运行数据不作为业务源码展开，外部模型服务的内部实现不在地图内。运行数据即使被 Git 跟踪，也不因此成为代码或架构定义。

结构变化时只更新对应事实源：总览维护入口与跨模块关系，模块页维护本域文件和链路，公共记录维护共享能力；内部实现变化但职责与边界未变时不增加流水。
