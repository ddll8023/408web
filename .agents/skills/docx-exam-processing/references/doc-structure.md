# 试题 Word 文档的结构约定

用于识别"按章节编号组织的真题合集"这类文档。实际文档若与本约定不同，以 `inspect_docx.py`
的勘察结果为准，不要按本文件强行套用。

## 典型结构

```text
1 时间复杂度                 ← 章节标题（编号即层级：1 → 1 级，2.1 → 2 级，3.1.1 → 3 级）
  2011年真题 第1题           ← 题目标题（所属章节的下一级）
    题目                     ← 题干区块标题
      ……题干、代码块、题目配图……
    选项                     ← 选项区块标题（综合/算法题可能没有）
      A./B./C./D.            ← 选项表格（2 列 4 行）
    答案                     ← 答案区起点
      正确答案：A。解析：……
      核心依据 / 解题过程 / 图示分析 / 易错点 / 选项辨析
      (1)(2)(3) 分问小节
```

## 识别要点

- **章节层级**：由标题文本开头的编号段数决定（`2.1` 是 2 级，`3.1.1` 是 3 级）；导出文档里
  这些标题常常被统一写成 Heading 1，需要按编号重排（见 `relevel_headings.py`）。
- **题目标题**：形如 `YYYY年真题 第N题`（可用 `--question-re` 覆盖）。题目标题级别 = 所属
  章节级别 + 1；题内 `题目`/`选项`/`答案` 再下一级，`核心依据`/`解题过程` 等再下一级。
- **选项表格**：2 列（字母列 + 内容列）、4 行；内容列常是单个公式或纯文本。可用
  `is_option_table()` 判定。
- **答案区边界**：从 `答案` 标题起，到下一个题目标题或章节标题之前的全部内容（含表格、
  代码块、图示）。每个题目的答案区互不重叠。
- **图片**：题干配图在题目区，解析图示在答案区；两者通常不共用同一图片部件，因此可按
  引用关系安全清理（见 `split_questions.py`）。

## 标题样式特征（决定能否只改样式）

这类从 Markdown/网页导出的文档，标题段通常**只有 `w:pStyle`**，没有直接字号、`outlineLvl`
或编号覆盖，因此：

- 改标题级别只需替换 `pStyle`，不影响正文与表格；
- 样式表里的字号未必逐级递减（曾出现 H3 比 H2 大、H4/H5 与 H2 同号），需要时另行调整
  `Heading 1..7` 的 `w:sz`；
- 正文常用直接字号覆盖 Normal 样式，判断"标题是否比正文大"必须看实际正文 run 的 `w:sz`，
  不能只看 Normal 样式。

## 勘察入口

```text
python scripts/inspect_docx.py "<file.docx>"
```

输出段落/表格/图片数量、标题层级分布、章节与题目计数、LaTeX 片段统计、公式与容器数量、
选项表格数量与单元格对齐分布，作为后续改动的基线。
