# 真题分类统计（页面与导出）

### 层级表达的通道分工

约定：层级只由权重带、标记与导轨表达，背景色只留一档（有下级的分类组）；「未归档」等状态不得使用背景色，改用左边线与标签；颜色分工为棕色给结构、蓝色给数据。

适用：`frontend/src/views/admin/ExamCategoryStats.vue` 的明细区。

原因：背景通道一旦被层级或多档状态占满，状态与层级的视觉权重会互相打架、倒挂。

### 页面与导出必须同一口径

约定：改页面明细区的表达方式时，必须同步 `backend-fastapi/src/web408/modules/reporting/exporters.py` 的导出；导出不再输出范围文案列，层级只用名称前的缩进表达（列数变化属对外的破坏性变更）。

原因：两处口径不一致时，用户会拿到与页面说法不同的导出文件。

### 已否决的做法与理由

约定：不要重新提出下列方案——四级奶油色阶分背景（彩度偏高、级差过小，观感脏）；斑马纹（可读性收益无证据，且会与层级底色抢通道）；逐行输出范围文案（非数据墨水，会让所有行权重相等）；把题量与题型集中放到行右端（名称与数字距离过远，无法判断归属）；固定树槽让名称列对齐（第三级之后标记压到文字上）。

原因：这些方案在本轮改造中已被逐项验证并否决，重提会重复试错。
